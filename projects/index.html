Projects

  • μKal

    A Kalman filtering library written in C for embedded systems. Implements estimators for linear and nonlinear systems (EKF or SOF) using only statically allocated memory, built to run in the most constrained environments.

  • μLAPack

    A small linear algebra package for matrix/vector operations, optimized for microcontrollers and embedded environments. Every operation is checked for initialization and dimensional legality before it runs, and it can be configured to work safely wherever dynamic memory allocation is a concern.

  • Master's Thesis in Computer Engineering

    Confidence-based field prediction and path planning methods for autonomous exploration vehicles.

  • The Jay Flight Controller

    Custom flight controller software for my senior design project, PAVx - a feedback controller for quad-copter flight, plus drivers and protocols for a 9DOF IMU, IR camera, wireless communication, and GPS. Built for a custom PCB around an Atmel AVR ATmega 328P (or any AVR MCU with minor changes). Jay lets a pod of drones communicate and scan an unknown area aerially and autonomously, feeding aggregated data to a ground station display in real time.

  • Pod-Based UAV Heat Seeking

    Simulates pod-UAV flight and an inverse-distance weighting algorithm so a simulated pod of drones can work together to predict unknown points on a field.

  • snOS — Sensor Node Operating System

    A framework for low-cost, low-powered IoT systems. Two or more microcontrollers running snOS can mesh into a network of sensor nodes that ultimately connects to the internet, publishing and subscribing to messages - including ones that can interrupt another controller's thread execution - for real-time, event-driven behavior.

  • Power Grid Modernization Research Lab

    Research building a controller board and firmware for smart household appliances, with the ability to remotely monitor and control them.

Smaller projects of mine can also be found on GitHub.
